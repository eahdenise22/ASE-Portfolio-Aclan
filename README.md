# Course Introduction
CPELX230-330 (Exploring Agentic Software Engineering and Responsible AI) focuses on how autonomous and semi-autonomous AI agents are engineered, deployed, and governed within real-world software systems. Building upon prior foundations in data science, machine learning, and deep learning architectures from Electives 1 and 2, this course shifts from training standalone models to integrating intelligent agents into reliable, maintainable software lifecycles using Agile/Scrum practices, Git version control, and AI risk management frameworks.


## Personal Learning Goals
- Architect Reliable Agentic Systems: Design AI agents with structured perception-action loops, memory, and tool-use boundaries rather than treating models as isolated scripts.
- Apply Collaborative Engineering Workflows: Practice disciplined Git version control (`clone`, `pull`, `commit`, `push`) and iterative Agile/Scrum cycles to manage evolving agent behaviors and requirements.
- Embed Responsible AI & Governance: Integrate safety guardrails, human-in-the-loop oversight, data privacy protection, and risk mitigation principles (aligned with the NIST AI RMF) into system design.
- Bridge AI Engineering to Real-World Applications: Connect intelligent agent workflows with scalable deployment and edge/distributed AI practices relevant to computer engineering.

## Reflection 

Completing the concept analysis in Part A clarified the shift from writing deterministic, rule-based software to engineering adaptive AI agents that perceive environments and act toward goals. While autonomy makes agents capable of handling dynamic, partially observable conditions, it also introduces risks such as hallucinations, goal misalignment, prompt injection, and unintended tool execution. Combining iterative Agile development and version control with strong human oversight and governance boundaries is essential to keep AI-enabled applications safe, accountable, and trustworthy.
